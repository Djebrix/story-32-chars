One Wi-Fi network name, exactly 32 characters, that tells a whole story: the dog ate the homework — and Dad. Written to `/output/entry.txt`.

Entry for the [Tell a Whole Story in 32 Characters](https://make.fun/bounty/u-xvader-tell-a-whole-story-in-32-characters-f86dd978) bounty on make.fun.

## Run

```sh
python3 main.py
```

Writes the name to `/output/entry.txt` (or `$ENTRY_OUTPUT_DIR/entry.txt` when set).
The program is Python 3 stdlib only, deterministic, and reads no input.
